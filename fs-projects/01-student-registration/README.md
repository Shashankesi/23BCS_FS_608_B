# Student Registration System (Day 1)

A basic Student Registration System showcasing full-stack integration with React, Node.js, Express, and MongoDB.

## Features
- Add student record (Name, Email, Phone, Course)
- Form validation on frontend & backend
- Edit student records
- Delete student records
- Dynamic state updates

## Project Structure
- `backend/`: Express server, Mongoose Student schema, API endpoints.
- `frontend/`: React Vite app, responsive vanilla CSS.

## Getting Started

### Backend Setup
1. Open a terminal and navigate to `backend`:
   ```bash
   cd backend
   npm install
   ```
2. Start the backend:
   ```bash
   npm start
   ```
   The backend will run on `http://localhost:5000` (defaults to local MongoDB connection).

### Frontend Setup
1. Open a terminal and navigate to `frontend`:
   ```bash
   cd frontend
   npm install
   ```
2. Start the client:
   ```bash
   npm run dev
   ```
   The frontend will run on `http://localhost:3000`.
